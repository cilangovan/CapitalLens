# T212 Portfolio Monitor

Monitors all Trading 212 pies + individual positions. Fires alerts via ntfy (phone push) and Gmail. Dashboard on GitHub Pages.

## Setup (one time)

### 1. Create GitHub repo
Create a **private** repo called `t212-monitor`. Push this code to it.

### 2. Add GitHub Secrets
Settings → Secrets and Variables → Actions → New repository secret

| Secret | Value |
|--------|-------|
| `T212_API_KEY` | Trading 212 API key |
| `T212_API_SECRET` | Trading 212 API secret |
| `GMAIL_USER` | your@gmail.com |
| `GMAIL_APP_PASS` | Gmail app password (not your login password) |
| `NTFY_TOPIC` | e.g. `hoop-t212-x7k29` |

### 3. Enable GitHub Pages
Settings → Pages → Source: Deploy from branch → Branch: `main` → Folder: `/dashboard`

Dashboard will be at: `https://yourusername.github.io/t212-monitor/`

### 4. Enable Actions
Actions tab → enable workflows if prompted.

### 5. Run manually first
Actions → T212 Portfolio Monitor → Run workflow

Check the logs — should show positions + pies fetched.

## Alert thresholds

| Alert | Threshold |
|-------|-----------|
| Dip alert | -8% from rolling high |
| Buy signal | -12% from rolling high |
| Trim / take profit | +40% from avg cost |
| Rebalance nudge | >5% drift from baseline |
| Growth lag | Annualised return < 7.5% (half of 15% target) |

Edit `monitor.py` lines 25-30 to adjust.

## Schedule

Runs every 15 minutes, Mon-Fri, 07:00-17:00 UTC (covers London market hours).
Email sent on first run, then every 6 runs (~90 min), and whenever there are alerts.

## Gmail app password

1. Enable 2FA on your Google account
2. Go to myaccount.google.com → Security → App Passwords
3. Generate password for "Mail"
4. Use that 16-char password as `GMAIL_APP_PASS`
